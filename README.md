# DetectiFi – Compliance Automation Tool for FinTechs

## Project Overview

DetectiFi is a **Compliance Automation Platform** built for **FinTech companies** to simplify and strengthen **KYC (Know Your Customer)** and **AML (Anti-Money Laundering)** processes.

The project focuses on **secure digital onboarding**, **identity verification**, and **financial risk detection** without depending on unreliable third-party government APIs.

---

## What the Project Does

* Allows users to upload **Aadhaar and PAN cards** for verification
* Uses **QR code scanning and OCR** to validate documents and prevent fake submissions
* Performs **Video KYC** with basic **liveness detection** (blink and motion checks)
* Verifies identity using multiple factors like **face image, document numbers, and signature**
* Generates an **automated compliance report** for quick review and approval

---

## AML & Risk Detection

* Analyzes financial behavior using **rule-based checks** and **machine learning models**
* Studies relationships between users, accounts, and entities instead of only individual transactions
* Helps compliance officers focus on **high-risk alerts first**

---

## Key Idea Behind the Project

DetectiFi treats compliance as a **continuous process**, not a one-time step. It aims to:

* Reduce fraud and money laundering risks
* Improve onboarding speed and user experience
* Support FinTechs with a **plug-and-play compliance solution**
* Bridge the gap between **traditional banks and modern FinTech platforms**

---

## Tech Stack (High-Level)

* Backend: FastAPI
* Technologies: OCR, QR Code Processing, Face Recognition, Liveness Detection
* AML Models: Rule-based logic + Machine Learning

---

## Use Case

DetectiFi can be integrated into any FinTech application that requires:

* Digital KYC
* AML monitoring
* Secure user onboarding
* Regulatory compliance automation
